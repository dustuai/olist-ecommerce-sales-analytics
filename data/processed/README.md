# Processed Data

This directory contains analysis-ready datasets generated during the Python analysis workflow.

## Purpose

Processed files are derived from the original Olist dataset and are used to support exploratory analysis and Power BI reporting.

Typical outputs include:

- Monthly sales summaries
- Category-level sales summaries
- State-level order summaries
- Delivery performance summaries
- Review analysis
- Other aggregated business-analysis datasets

## Important

These files are derived outputs and are not the original Olist dataset.

The exact files included in this directory depend on the final analysis workflow.
