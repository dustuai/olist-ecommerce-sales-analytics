# Raw Dataset

The raw Olist dataset is not included in this GitHub repository.

## How to get the data

1. Download the **Brazilian E-Commerce Public Dataset by Olist** from Kaggle:
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

2. Extract the ZIP.

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

The dataset contains relational data covering orders, customers, sellers, products, payments, reviews, geolocation, and product category translations.

## Dataset Source

The dataset can be obtained from the original Olist dataset source used for this project.

## Required Files

The analysis expects the original Olist CSV files, including:

- `olist_customers_dataset.csv`
- `olist_geolocation_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_orders_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `product_category_name_translation.csv`

After downloading the dataset, place the CSV files inside this `data/raw/` directory.

## Important

Raw dataset files are excluded from GitHub through `.gitignore`.
